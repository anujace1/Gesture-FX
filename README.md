This is a OpenCV project, made using mediapipe library. 
I've learned various things from various tutorials and websites. However most of the tutorials have become obsolete since Mediapipe updated to 5.0.0.
Basics were learned from geeksforgeek.com OpenCV tutorials.
Because of the changes after the update, most of the project was made by scouring the official Mediapipe website.
The filters were learned from various StackOverflow posts, as I don't understand numpy enough to make it entirely myself.
6 of the 9 filters were taken from posts.
